下面这几条规则写在条款和售后流程里，买前值得知道：

- **IP 被墙的处理**：开通 72 小时内 IP 被封可以免费换一次；之后每次换 IP 收 $3，面板可自助操作。
- **流量翻倍**：促销套餐购买后在 LowEndTalk 论坛留订单号可以申请免费流量翻倍，这个活动长期有效，很多人不知道。
- **退款政策偏硬**：条款层面不支持常规退款，没有 money-back guarantee。遇到 IP 被墙、机房故障这类质量问题可以走工单争取换 IP、迁移机房，另有 SLA 宕机补偿可向账务部门申请。所以建议策略是先买最便宜的年付款试水，合适了再加购。
- **IPv6 只有部分机房有**：洛杉矶和法国机房可开工单申请最多 100 个免费 IPv6 地址，其他机房暂不支持。需要 IPv6 的话下单前确认机房。
- **普通 VPS 不带 Windows**：需要 Windows 要买专门的 Windows VPS 产品线（Ryzen 平台，可选 Server 2012/2016，带完整管理员权限和 RDP）。
